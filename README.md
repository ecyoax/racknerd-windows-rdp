## 从下单到 mstsc 连上，自装流程就五步

全过程大约 20–40 分钟，操作都发生在 RackNerd 的 SolusVM 管理面板和一个 VNC 窗口里。给电脑重装过系统的人，做这件事没有任何门槛。

1. **下单等开通邮件。** 年付 KVM 套餐付款后，欢迎邮件里有 VPS 信息和 SolusVM 面板登录，通常几分钟到几小时内自动开通。
2. **挂载 ISO。** 在 SolusVM 里找到自定义 ISO 选项，粘贴 Windows Server 评估镜像的直链（微软官网评估中心可下载），等待挂载完成后设为启动项。
3. **VNC 里装系统。** 打开 VNC 控制台，像普通装机一样走完安装向导。常见的坑：安装到选择磁盘那一步认不到硬盘，需要加载 virtio 驱动镜像，卡住的人基本都卡在这里。
4. **进系统开远程桌面。** 系统属性里允许远程连接，确认勾选 NLA（网络级身份验证），防火墙放行，顺手把默认的 3389 端口改掉。
5. **本地连接。** win+R 输入 mstsc，填 IP 和管理员密码，一个完整的 Windows 桌面就出现在你屏幕上。

除了 ISO 安装，社区里还流传 DD 镜像的做法（一条命令把做好的 Windows 镜像写入硬盘），速度快得多，但镜像来源必须可靠——来路不明的镜像等于把别人的后门装进自己系统。拿不准来源，老实用官方评估 ISO。

## 自装路线的坑：买前把这五条看完

这条路线的技术门槛其实不高，真正需要提前准备的是心理预期：省下的钱对应着三件你自己的事——授权、安全、售后。

1. **没有 Windows 售后。** RackNerd 的技术支持管硬件、网络和面板层面的问题，系统蓝屏、驱动异常不归它管，标准解法是 SolusVM 里重装再来一遍。试错成本低，但别指望有人手把手。
2. **授权自己解决。** RackNerd 不提供也不代售 Windows 授权。Windows Server 评估镜像有效期 180 天（微软官方的分发方式），到期后自己购买授权或重装系统。前面算出的差价，有一部分就是从这里省出来的。
3. **安全自己配。** 预装服务商（比如 OwnWebServers）出厂就带 NLA、防火墙规则和防爆破配置，自装路线这些全要自己来：开启 NLA、改掉 3389 端口、防火墙限制来源 IP、设强密码、及时打补丁。每一条都不难，麻烦的是一条不做——默认端口直接暴露在公网上，每天都会被扫描器爆破。
4. **内存门槛。** 1GB 内存跑不动 Windows 图形界面；2GB 能装 Windows Server，多开程序会卡；4GB 才是日常远程桌面的实用线。想装 Windows，768MB 和 1GB 档直接跳过。
5. **流量不是无限。** RackNerd 的流量按月固定（750GB–4TB 档）。轻量远程桌面每月只消耗几个 GB，绰绰有余；拿它当文件服务器或下载机就要先算账了，标着“不限流量”的预装服务商在这点上更宽松。
